# Quarterly Business Review (QBR) Template — Multi-Product Company

## Seed Classification
- **Domain**: Cross-Business Operations
- **Applies To**: Stone AI (Web SaaS), Best AI Mobile (React Native), Stone AI Tools (API Marketplace)
- **Owner**: Agent Stone (Head 1) + Cardinal (Head 2)
- **Created**: 2026-03-09
- **Sensitivity**: Internal — Strategic

---

## 1. Purpose

The Quarterly Business Review is a structured assessment of the Three-Headed Monster's performance across all three products. It provides the founder with a complete picture of where the business stands, what worked, what didn't, and what to prioritize next quarter. This template is designed for a multi-product company operating as a single ecosystem.

## 3. QBR Process

### 3.1 Preparation Timeline

```
T-2 weeks: Stone begins data collection
  - Pull all metrics from analytics
  - Compile support data
  - Gather agent performance data

T-1 week: Cardinal delivers competitive intelligence
  - Market landscape update
  - Win/loss analysis
  - Technology trend assessment

T-3 days: Stone assembles draft QBR
  - All sections filled with data
  - Preliminary grades assigned
  - Draft recommendations

T-1 day: All heads review
  - Stone, Cardinal, Chaos review draft
  - Each head adds their perspective
  - Final grades agreed

T-0: QBR presented to founder
  - 2-hour review session
  - Decisions made
  - Action items assigned
  - Next quarter goals set
```

### 3.2 QBR Calendar

```
Q1 Review: April 1-7
Q2 Review: July 1-7
Q3 Review: October 1-7
Q4 Review: January 1-7

First QBR: Q2 2026 (covers Q1: Jan-Mar 2026)
```

## 4. Grading Rubric

### 4.1 Quarterly Grade Scale

| Grade | Definition | Criteria |
|-------|-----------|----------|
| A | Exceptional | Exceeded all targets, no major issues |
| B | Good | Met most targets, minor issues resolved |
| C | Satisfactory | Met some targets, issues need attention |
| D | Below expectations | Missed most targets, significant concerns |
| F | Failing | Critical issues, immediate intervention needed |

### 4.2 Category Weights

```
Overall Quarter Grade = weighted average:
  Revenue:    35% weight
  Growth:     25% weight
  Product:    25% weight
  Operations: 15% weight
```
