## 1. Executive Summary

Trademarks protect the brand names, logos, and slogans that distinguish your products and services in the marketplace. For the Three-Headed Monster portfolio, trademark registration is essential to prevent competitors from using confusingly similar names, to build brand equity, and to establish enforceable intellectual property rights. ## 2. Trademark Fundamentals

### 2.1 What Can Be Trademarked

| Type | Examples | Registrable? | Stone AI Marks |
|------|---------|-------------|---------------|
| Word marks | Brand names, product names | Yes | "Stone AI", "Best AI", "Stone AI Tools" |
| Design marks | Logos, stylized text | Yes | Concept E insignia, Three-Headed Monster logo |
| Slogans | Taglines, catchphrases | Yes | Any taglines used in marketing |
| Sound marks | Jingles, sounds | Yes (less common) | Not currently applicable |
| Trade dress | Product packaging, UI design | Yes (harder to register) | Potentially the UI aesthetic |

### 2.2 Trademark Strength Spectrum

From weakest to strongest:

1. **Generic** (not registrable): "AI Chat Service"
2. **Descriptive** (registrable only with secondary meaning): "Smart AI Assistant"
3. **Suggestive** (registrable): "Stone AI" — suggests quality/durability but doesn't describe the service
4. **Arbitrary** (strong): Common word in unrelated context — e.g., "Apple" for computers
5. **Fanciful** (strongest): Made-up words — e.g., "Xerox", "Kodak"

**Stone AI Assessment**:
- "Stone AI" — Suggestive/Arbitrary (stone doesn't describe AI services) — Good strength
- "Best AI" — Potentially descriptive (claims to be "best") — Moderate risk of rejection; may need to show secondary meaning or argue it's suggestive in context
- "Three-Headed Monster" — Arbitrary — Strong
- "Concept E" — Arbitrary/Fanciful — Strong

### 2.3 Trademark vs. Copyright vs. Patent

| Protection | What It Covers | Duration | Cost | Relevance |
|-----------|---------------|----------|------|-----------|
| Trademark | Brand names, logos, slogans | Indefinite (with renewal) | $250-$750+ per class | HIGH — brand protection |
| Copyright | Creative works (code, text, images) | Life + 70 years | Free (automatic), $65 registration | HIGH — code and content |
| Patent | Inventions, processes | 20 years | $5,000-$15,000+ | LOW — AI algorithms hard to patent |
| Trade Secret | Confidential business info | Indefinite (if maintained) | Free (operational cost) | HIGH — AI prompts, models |

## 3. USPTO Filing Process

### 3.1 Pre-Filing: Trademark Search

Before filing, conduct a comprehensive trademark search to avoid rejection and infringement:

```
SEARCH STRATEGY:

1. USPTO TESS DATABASE (Free)
   - URL: https://tess2.uspto.gov/
   - Search for exact match and phonetic equivalents
   - Search in all relevant classes
   - Check both live and dead marks (dead marks may still have common law rights)

2. STATE TRADEMARK DATABASES
   - NY DOS trademark search
   - Other states where you'll operate

3. COMMON LAW SEARCH
   - Google search for the name + similar services
   - Domain name search
   - Social media handle search
   - App store search
   - Business name registrations

4. EVALUATION CRITERIA
   - Same or similar name? (phonetic, visual, conceptual similarity)
   - Same or related goods/services?
   - Same or overlapping trade channels?
   - Same or overlapping consumer base?
   - If any overlap: HIGH risk of rejection or opposition

SEARCH FOR STONE AI MARKS:
- "Stone AI" — Search for "stone" + "AI/artificial intelligence" combinations
- "Best AI" — Search for "best" + "AI" combinations (likely many results)
- "Three-Headed Monster" — Search for exact and similar phrases
- "Concept E" — Search for exact and similar marks
```

### 3.2 Choosing the Right Filing Basis

| Filing Basis | When to Use | Requirements |
|-------------|-------------|-------------|
| **Use in Commerce (1(a))** | Already using the mark in interstate commerce | Specimen showing current use |
| **Intent to Use (1(b))** | Plan to use the mark but haven't yet | Statement of bona fide intent; must file Statement of Use before registration |
| **Foreign Registration (44(e))** | Have a foreign registration | Copy of foreign registration |
| **Foreign Application (44(d))** | Have a pending foreign application | Copy of foreign application |

**Stone AI**: File on Use in Commerce (1(a)) for marks already in use (Stone AI, stone-ai.net is live). File Intent to Use (1(b)) for marks not yet in commerce (Best AI, Stone AI Tools if not yet launched).

### 3.3 TEAS Plus vs. TEAS Standard

| Feature | TEAS Plus | TEAS Standard |
|---------|-----------|---------------|
| Filing fee per class | $250 | $350 |
| Description of goods/services | Must select from USPTO ID Manual | Can write custom description |
| Communication | Must accept email correspondence | Can accept email or paper |
| Additional requirements | Must meet all TEAS Plus requirements at filing | More flexible |
| Savings per class | $100 less | N/A |

**Recommendation**: Always try TEAS Plus first ($250/class). Only use TEAS Standard if your goods/services description doesn't fit the ID Manual options.

### 3.4 Selecting Classes

Trademarks are registered in specific international classes. Each class costs a separate filing fee.

**Relevant Classes for Stone AI**:

| Class | Description | Relevant Products/Services |
|-------|-------------|---------------------------|
| **Class 9** | Computer software, apps, downloadable software | Mobile apps (Best AI), downloadable tools |
| **Class 42** | SaaS, cloud computing, software development | Stone AI platform, Stone AI Tools, AI services |
| **Class 35** | Advertising, business management, online marketplace | If offering business/marketing AI tools |
| **Class 38** | Telecommunications, chat services | If the chat/communication aspect is primary |
| **Class 41** | Education, entertainment, training | If offering educational AI content |

**Priority Classes** (within $2,100 budget):
1. **Class 42** (most important) — Covers SaaS and AI services
2. **Class 9** (second priority) — Covers software and apps

## 5. Specimen Requirements

### 5.1 What Is a Specimen?

A specimen is evidence that you are actually using the trademark in commerce in connection with the identified goods/services.

### 5.2 Acceptable Specimens by Class

**Class 42 (Services) — "Use in Commerce" specimens**:
- Screenshot of the website showing the mark AND the services being offered
- Screenshot of the app store listing
- Advertising materials showing the mark in connection with the services
- Marketing emails or social media posts showing the service mark

```
GOOD SPECIMEN: Screenshot of stone-ai.net homepage showing:
- "Stone AI" name prominently displayed
- Description or display of AI SaaS services
- URL bar showing the domain
- Date captured

BAD SPECIMEN:
- Just the logo alone without services context
- An internal document not available to consumers
- A mockup or spec that isn't live
```

**Class 9 (Goods — Software) — "Use in Commerce" specimens**:
- Screenshot of the software showing the mark
- App store listing showing the mark on the app
- Screenshot of download page
- Product packaging (digital products: the "packaging" is the download/access page)

### 5.3 Specimen Preparation Tips

```
SPECIMEN PREPARATION CHECKLIST:

[ ] Screenshot is clear and legible
[ ] Mark is visible and prominent in the screenshot
[ ] Services/goods are described or shown in the screenshot
[ ] Screenshot shows the mark as actually used (not a mockup)
[ ] Screenshot includes URL (for websites)
[ ] Screenshot is dated or URL is verifiable
[ ] File format: JPG or PDF
[ ] File size: Under 5MB per image
[ ] Resolution: At least 300 DPI for print, clear for screen
```

## 6. Filing Step-by-Step

### 6.1 Create USPTO Account

1. Go to https://www.uspto.gov/
2. Create a USPTO.gov account
3. Verify email
4. Access TEAS filing system

### 6.2 TEAS Plus Filing Walkthrough

```
STEP 1: Select TEAS Plus or TEAS Standard
→ Select TEAS Plus ($250/class)

STEP 2: Mark Information
→ Mark type: Standard Characters (for word marks) or Design Mark (for logos)
→ Enter the mark exactly as used: "STONE AI"

STEP 3: Goods/Services
→ Select from ID Manual
→ Choose Class 42
→ Select appropriate descriptions
→ Add Class 9 if filing in multiple classes

STEP 4: Filing Basis
→ Section 1(a) Use in Commerce: provide date of first use + specimen
→ Section 1(b) Intent to Use: provide statement of bona fide intent

STEP 5: Owner Information
→ Owner: [Company Name] LLC (or individual if no entity yet)
→ Address
→ Entity type: Limited Liability Company
→ State of organization: New York

STEP 6: Correspondent Information
→ Email address for correspondence
→ Mailing address

STEP 7: Attorney Information
→ If filing yourself: indicate no attorney (pro se)
→ If using attorney: attorney's information

STEP 8: Specimen Upload (if Use in Commerce)
→ Upload JPG or PDF specimen
→ Describe what the specimen shows

STEP 9: Signature
→ Type /Your Name/ as electronic signature
→ Signatory's position: Owner / Member / Manager

STEP 10: Payment
→ Credit card, debit card, deposit account, or electronic funds transfer
→ $250 per class (TEAS Plus)

STEP 11: Review and Submit
→ Review all information carefully
→ Submit application
→ Save confirmation/receipt with serial number
```

### 6.3 Post-Filing Timeline

```
TRADEMARK APPLICATION TIMELINE:

Month 0: Application filed
→ Receive serial number and filing receipt

Months 1-3: Waiting period
→ Application assigned to examining attorney

Months 3-6: Examination
→ Examining attorney reviews application
→ If issues: Office Action issued (6-month response deadline)
→ If no issues: approved for publication

Months 6-9: Publication
→ Mark published in Official Gazette for 30 days
→ Any third party can file an opposition during this period

Months 9-12: Registration (Use in Commerce) or NOA (Intent to Use)
→ If Use in Commerce: Registration certificate issued
→ If Intent to Use: Notice of Allowance issued
   → Must file Statement of Use within 6 months (extensions available)

TOTAL TIMELINE: 8-14 months (typical, no complications)
                12-24 months (with office actions or oppositions)
```

## 7. Common Office Actions and Responses

### 7.1 Likelihood of Confusion (Section 2(d))

The most common rejection. The examiner finds a similar existing mark.

**Response Strategy**:
- Argue marks are sufficiently different (appearance, sound, meaning)
- Argue goods/services are different
- Argue trade channels are different
- Argue consumer sophistication
- Submit evidence of coexistence in the marketplace
- Consent agreement from the cited mark owner (if obtainable)

### 7.2 Descriptiveness (Section 2(e)(1))

The examiner finds the mark merely describes the goods/services.

**Response Strategy**:
- Argue the mark is suggestive, not descriptive (requires imagination to connect)
- Submit evidence of acquired distinctiveness (5 years of use, advertising spend, consumer recognition)
- Accept registration on the Supplemental Register (lesser protection but establishes priority)
- Amend to Supplemental Register as fallback

**Risk for "Best AI"**: High likelihood of descriptiveness rejection. "Best" is laudatory and potentially descriptive for AI services. Prepare arguments that it's a fanciful brand name in context, or plan for Supplemental Register.

### 7.3 Specimen Refusal

The examiner finds the specimen inadequate.

**Response**: Submit a substitute specimen that clearly shows the mark in use in connection with the goods/services.

### 7.4 Description of Goods/Services Issues

The examiner requires amendments to the goods/services description.

**Response**: Amend description per examiner's suggestions or propose alternative language from the ID Manual.

## 8. Post-Registration Maintenance

### 8.1 Required Filings

| Filing | Deadline | Fee | Consequence of Missing |
|--------|----------|-----|----------------------|
| Section 8 Declaration of Continued Use | Between 5th and 6th year after registration | $225/class | Registration cancelled |
| Section 15 Declaration of Incontestability | Between 5th and 6th year (with § 8) | $200/class | Lose incontestability benefit |
| Section 8 & 9 (Renewal) | Between 9th and 10th year, then every 10 years | $225 (§8) + $300 (§9) per class | Registration expires |

### 8.2 Maintenance Calendar

```
REGISTRATION DATE: [Date]

Year 5-6: File Section 8 + Section 15
  - Section 8: Declaration of Continued Use ($225/class)
  - Section 15: Declaration of Incontestability ($200/class)
  - Total: $425/class
  - DEADLINE: 6th anniversary of registration (6-month grace with $100 surcharge)

Year 9-10: File Section 8 + Section 9
  - Section 8: Declaration of Continued Use ($225/class)
  - Section 9: Renewal ($300/class)
  - Total: $525/class
  - DEADLINE: 10th anniversary (6-month grace with $100 surcharge per section)

Every 10 years thereafter: Section 8 + Section 9 renewal
```

## 9. Monitoring and Enforcement

### 9.1 Trademark Monitoring

```
MONITORING STRATEGY:

1. USPTO MONITORING:
   - Set up alerts for new filings similar to your marks
   - Check Official Gazette weekly for similar marks in publication
   - Use free monitoring: USPTO TSDR system email alerts

2. DOMAIN MONITORING:
   - Monitor new domain registrations containing your marks
   - Tools: Google Alerts, domain watchlist services
   - Check common TLDs: .com, .net, .org, .io, .ai, .app

3. APP STORE MONITORING:
   - Regularly search app stores for similar names
   - Set up Google Alerts for mark names

4. SOCIAL MEDIA:
   - Monitor social media for infringing use
   - Register handles on all major platforms

5. WEB MONITORING:
   - Google Alerts for all registered marks
   - Monthly manual search for potential infringers
```

### 9.2 Enforcement Actions (Escalation Ladder)

```
LEVEL 1: INFORMAL CONTACT
- Friendly email or message to the infringer
- Often sufficient for small or unintentional infringers
- Document the communication

LEVEL 2: CEASE AND DESIST LETTER
- Formal letter on company letterhead (or through attorney)
- Identify your trademark registration
- Describe the infringing use
- Demand they stop within a specified period (15-30 days)
- State consequences of non-compliance
- Send via certified mail or email with delivery confirmation

LEVEL 3: PLATFORM ENFORCEMENT
- DMCA/trademark takedown on social media platforms
- App store trademark complaint
- Domain dispute (UDRP) for infringing domains
- Amazon/marketplace brand registry complaint

LEVEL 4: USPTO OPPOSITION/CANCELLATION
- File opposition during 30-day publication period ($600/class)
- File cancellation petition for registered marks ($600/class)
- Can be done pro se or with attorney

LEVEL 5: FEDERAL LITIGATION
- File trademark infringement lawsuit in federal court
- Seek injunction, damages, attorney's fees
- Expensive ($50K-$500K+) — last resort
- Consider contingency fee attorneys
```

## 11. Common Law Trademark Rights

Even before federal registration, you have common law trademark rights through actual use:
- Protection limited to geographic area of use
- No presumption of nationwide ownership
- Harder to enforce than registered marks
- Use the ™ symbol for unregistered marks
- Use the ® symbol ONLY after federal registration

**Immediate Action**: Start using ™ on all marks in all marketing materials, website, and app immediately. Switch to ® only after registration is granted.
